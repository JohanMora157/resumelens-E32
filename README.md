# ResumeLens

ResumeLens es un sistema general para el procesamiento y evaluación de hojas de vida mediante modelos de teoría de lenguajes formales, diseñado para determinar si las cualificaciones de un candidato satisfacen los patrones definidos para perfiles profesionales específicos.

## Project Structure
- `src/`: Código fuente principal de la aplicación, organizado en módulos para extracción, normalización, clasificación, gramática y modelos compartidos.
- `tests/`: Pruebas automatizadas correspondientes a cada una de las fases del sistema.
- `docs/`: Documentos de diseño, formalización, pruebas y registro de uso de IA (`ai-usage.md`).
- `data/`: Conjuntos de hojas de vida de prueba y ejemplos de desarrollo.
- `output/`: Resultados estructurados y visualizaciones generadas por el sistema.
